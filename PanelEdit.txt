CloudFlare Setup:
- CloudFlare Email: Your email for cloudflare profile
- CloudFlare Api Key: Your Global Api Key for your cloudflare profile
- Add your domain(s) to cloudflare

Don't forget to set IP alias to allocations in every node.




After all code inserted to code and app and resources and database and vendor folder pasted. Please run this commands (in /var/www/pterodactyl/):
- yarn install
- yarn run build:production
- php artisan route:clear && php artisan cache:clear && php artisan view:clear
- php artisan migrate
